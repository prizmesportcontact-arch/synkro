# Synkro

Une équipe d'agents IA connectés, directement dans le navigateur.

- **Mission Control** : tu donnes un objectif, le Chef d'équipe le découpe en tâches, les agents bossent (en parallèle quand c'est possible) en se passant leur travail, le Critique relit, et le Chef assemble le résultat final.
- **Labo** : la même demande envoyée à plusieurs agents, avec un verdict du Critique.
- **Chat** : discussion directe avec un agent.
- **Agents** : chaque agent a son IA (Gemini, ChatGPT ou Claude), son modèle, son rôle et ses consignes.
- **Outils** : palettes de couleurs, QR codes, générateur de noms par IA, outils texte.

## Clés API

Les clés se collent dans **Paramètres** et restent **uniquement dans ton navigateur** (localStorage).
Ne mets jamais de clé dans le code de ce dépôt.

- Gemini : https://aistudio.google.com/apikey (gratuit avec quota)
- ChatGPT : https://platform.openai.com/api-keys
- Claude : https://console.anthropic.com/settings/keys

Sans clé, tout tourne en **mode démo** (réponses simulées).
